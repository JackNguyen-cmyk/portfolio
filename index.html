01About me

A short story, told quickly.

I like the parts of software people never see: the API that doesn't fall over, the permission rule that can't be bypassed, the load test that proves it holds. Then I make sure the part they do see is easy to use.

  1. Chapter 01

    Builder

    From a WebSocket feed load-tested to 10,000 subscribers to production APIs at PosApp, I learn backend engineering by measuring instead of guessing.

  2. Chapter 02

    Teacher

    I TA Cornell's CS 1110, and before that I taught programming to hearing-impaired students. Explaining code clearly makes me write it more clearly.

  3. Chapter 03

    For good

    With Hack4Impact I build software for nonprofits, and since 2022 I've been part of Green Sphere and Tech-For-Love, which I co-led as president.
