# Portfolio

My personal portfolio site: projects, experience, and contact.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 5173
```

Includes a light/dark theme, a project browser (click, arrow keys or swipe), and a live Ithaca clock.
Project data lives at the top of `script.js`.
